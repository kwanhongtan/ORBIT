# ORBIT

## How to Run

Install Node.js 24 LTS (includes npm), then open a terminal in the project folder:

```sh
npm install
npm run build
npm start
```

Open http://127.0.0.1:4173/ in your browser.

Keep the terminal open while using the app. Press Ctrl+C to stop it.

After changing frontend code, run `npm run build` again and restart the server.

No Gemini API key is required for the current version. Local records are saved in `data/orbit-db.json`.

If Windows does not recognize `node` or `npm`, install Node.js and reopen your terminal.
